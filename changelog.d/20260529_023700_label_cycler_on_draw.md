### Added

- A new "Cycle labels" checkbox in the draw popover. When enabled, the
  default label automatically advances to the next applicable label after
  each object is drawn, so consecutive objects get successive labels
  (wrapping around the label list). A "Next object set to ..." message is
  shown on each switch.
